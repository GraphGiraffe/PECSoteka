# Идентификатор установки PWA

Стабильный manifest ID: `/pecsoteka`. Он вычисляется относительно origin start_url. Значение `./` здесь ошибочно: оно превращается в корень домена и конфликтует с соседними PWA, даже если их scope и кеши разделены. start_url и scope остаются `./`.

Это изменение установочной идентичности. Старую конфликтующую Linux-установку может понадобиться удалить и установить заново. Перед этим сохраните резервную копию через редактор → настройки → экспорт. При удалении не выбирайте очистку данных сайта: она может удалить альбомы всех приложений этого origin. Уже установленные Android-приложения не требуют массовой очистки: их обновление/миграция проверяются отдельно.

ID установки не меняет origin хранилища. IndexedDB `pecsoteka`, ключи `pecsoteka-*` и service worker в `/PECSoteka/` сохраняются. Смена ID не является миграцией пользовательских данных и не изолирует весь origin от соседних приложений.

Правило разрешения ID: [Web Application Manifest, id member](https://www.w3.org/TR/appmanifest/#id-member). Регрессионная проверка использует вычисленный Chromium `manifest.id` из `Page.getAppManifest`, а не разрешение URL относительно каталога manifest.
