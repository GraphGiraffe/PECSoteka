# Проверка 0.1.1

26 октября 2026, Node.js 22, Google Chrome на Linux. Проверена готовая сборка `dist/`, кеш `75d012b80dea`.

- `npm test`: 12/12 unit-тестов, включая адреса карточек, вставку со сдвигом и числа прописью.
- `npm run build`: 50 файлов оболочки и ресурсов, дополнительно `.nojekyll`.
- `npm run test:e2e`: 19/19 браузерных сценариев. Предыдущие сценарии общения, фото, транзакций, экспорта/импорта и работы без сети сохранены.
- Кнопка установки расположена непосредственно после настроек в панели редактора. Подтверждён вызов установочного API, скрытие после `appinstalled` и сохранение признака установки после перезагрузки. Панель с обеими кнопками помещается на 320 px.
- Через настоящий service worker загружена следующая версия в `waiting`. В детском режиме окно не появляется; в редакторе предложение появляется один раз. После «Позже», выхода из редактора и перезагрузки оно не повторяется; сообщение и кнопка остаются в настройках. Применение активирует новый worker, перезагружает в режим общения и сохраняет альбом без изменений.
- При отмене подтверждения закрытия формы несохранённое имя остаётся в поле. Экспорт/импорт и сброс используют окна приложения. Тест отклоняет любой вызов браузерного message-dialog.
- Сенсорный жест и колесо над заголовком перемещают только карточки по обеим осям. Геометрия заголовка и данные альбома остаются прежними.

Установка проверялась на границе браузерных событий/API. Реальная установка на Android/iPadOS и обнаружение установки в отдельной вкладке зависят от сигналов браузера; ограничения описаны в README. Нативный установщик и системный выбор файла не заменяются имитацией. Речь и камера имеют прежние границы проверки из `verification-0.1.md`.
