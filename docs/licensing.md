## Что разрешено без отдельного договора

| Сценарий | Условия |
| --- | --- |
| Семья пользуется альбомом | Бесплатно |
| Специалист использует альбом на платном занятии | Разрешено: оплата за работу человека, без платы за приложение |
| Коммерческий центр использует альбом для коммуникации | Разрешено на тех же условиях |
| Внутренние доработки для собственных занятий | Разрешены; без распространения и удалённого доступа публиковать их не требуется |
| Бесплатно распространяется изменённая версия | Та же лицензия, атрибуция, общедоступные соответствующие исходники |
| Изменённая версия предоставляется через сайт | Те же условия, ссылка на исходники в интерфейсе |
| Добровольные пожертвования | Допустимы без обязательной оплаты, привилегий и закрытых функций |
| Продажа приложения или платный доступ | Только по отдельному письменному разрешению |
| Платные функции, установка за плату, рекламная монетизация внутри приложения | Только по отдельному письменному разрешению |
| Включение кода в коммерческий программный продукт | Только по отдельному письменному разрешению |

Изменения и используемые защищённые фрагменты нельзя распространять под более
закрытыми условиями. Требование открытости касается производных работ, а не
любой независимой программы, размещённой рядом. Медицинские записи, фотографии
пользователей, секреты и другие персональные данные публиковать не требуется.

## Возможность коммерческого выпуска автором

GraphGiraffe сохраняет возможность отдельно продавать приложение и выдавать
коммерческие лицензии в пределах принадлежащих ему прав. Публичная лицензия
не отчуждает авторские права и не запрещает правообладателю заключать другие
договоры. Она также не даёт ему чужие права автоматически.

Для чужих доработок нужно отдельное согласие на коммерческое использование и
перелицензирование. Порядок явного согласия зафиксирован в [CONTRIBUTING.md](../CONTRIBUTING.md)
и шаблоне PR. Сам факт открытия PR не считается таким согласием. Если оно
отсутствует, вклад не принимается в upstream; автор может вести самостоятельный
некоммерческий форк по публичной лицензии.

- `d5d7260c85b73a7fa69892bdf2ed4154fb099d12` — стабильная ветка `main`.

Это относится и к публичной ветке `docs/licenses` с коммитом

Новые условия не отзывают уже предоставленные права. Прежний код можно продолжать
использовать, изменять и распространять по GPL, включая коммерческое использование
при соблюдении GPL. Совпадающие с ним части не становятся исключительно
некоммерческими от одной замены файла LICENSE. Старый текст сохранён в
[licenses/GPL-3.0-legacy.txt](../licenses/GPL-3.0-legacy.txt); это историческая
лицензия, а не утверждение, что новые добавления автоматически лицензированы по GPL.

Следовательно, эта смена условий фиксирует новое предложение правообладателя и
условия для новых материалов, но **не обеспечивает исключительную коммерческую
монополию на уже опубликованную GPL-версию**. Удаление веток или переписывание
истории не отменило бы выданные права. История и опубликованные релизы сохраняются.

Основания: [GPL v3, разделы 2 и 10](https://www.gnu.org/licenses/gpl-3.0.en.html),
[GNU о нескольких лицензиях одного правообладателя](https://www.gnu.org/licenses/gpl-faq.en.html#ReleaseUnderGPLAndNF).

Сборка включает LICENSE, THIRD_PARTY_NOTICES.md и каталог licenses. При
распространении нужно также предоставить соответствующие исходники конкретной

используйте исходники точного коммита или тега; ссылка только на изменяющуюся
главную ветку не заменяет исходники выпущенной версии.

Старые опубликованные архивы и теги не заменяются задним числом.
У сторонних компонентов свои лицензии; см. [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

## Границы этой схемы

Коммерческие ограничения делают эту лицензию source-available, а не open source
по [определению OSI](https://opensource.org/osd). Это индивидуальный текст,
а не стандартная GPL с добавленным запретом: такие ограничения нельзя просто
навязать получателям GPL-копии. CC BY-NC-SA также не используется как лицензия
кода: [Creative Commons не рекомендует свои лицензии для ПО](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software).

Лицензия фиксирует условия правообладателя, но не является технической защитой
от копирования и не гарантирует предотвращения нарушений. Для оценки
исполнимости индивидуальных условий и будущих коммерческих договоров нужна
юридическая проверка с учётом применимого права.
