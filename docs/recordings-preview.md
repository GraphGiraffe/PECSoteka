# Превью собственных озвучек

Следующий выпуск в ROADMAPler — **0.2.0**, карточка `recorded-voice`.
Кандидат для проверки: **0.2.0-preview.1**. Production не публикуется до проверки
владельцем. Роадмап до этого момента имеет статус проверки, а не завершённого релиза.

## Проверка пользователем

1. Откройте HTTPS-ссылку превью. Удерживайте замок, пройдите проверку взрослого
   и откройте карточку кнопкой редактирования.
2. В разделе «Своя озвучка» нажмите «Записать», разрешите микрофон, произнесите
   фразу и нажмите «Завершить запись». Прослушайте и сохраните карточку.
3. Откройте её ещё раз и запишите новый дубль или загрузите аудиофайл. Прослушайте
   старую и новую записи, выберите, какую сохранить, и сохраните карточку.
4. В настройках выберите «Только мои записи». Составьте сообщение из озвученных
   карточек и нажмите «Произнести». Проверьте порядок и остановку. Для карточек
   без записи можно выбрать «Мои записи, иначе синтез».
5. Перезагрузите приложение, проверьте воспроизведение без сети и экспорт/импорт
   копии. Рекомендуется проверить на целевом планшете с настоящим микрофоном.

Превью имеет отдельное хранилище и не получает ваш альбом автоматически. При
необходимости экспортируйте альбом из основной версии и импортируйте в превью.
Новые резервные копии с записями читаются версией 0.2.0 и новее.

## Сборка и размещение

```sh
npm test
npm run build
npm run test:e2e
npm run build -- --preview
```

Предпросмотр создаётся из `dist/` и размещается в отдельном каталоге
`artifacts/preview-0.2.0-preview.1/public/`. Внешний маршрут:
`https://seth.tail6aebd4.ts.net:10000/pecsoteka-preview/`.
Фактическое успешное размещение фиксируется в `publication.json` рядом со сборкой.

Используется тот же Tailscale Funnel, что у PlayRoom: добавляется только отдельный
`--set-path`, без reset, смены корневых обработчиков и перезапуска Tailscale.
Порт 10000 выбран потому, что его текущий корневой service worker измерительного
стенда пропускает сетевые запросы; корневой PWA PlayRoom на других портах не
используется как родитель превью. Сохраняются остальные обработчики и AllowFunnel.

Исходники и credentials не публикуются. Содержимое пользовательского альбома,
фото и озвучки находятся в браузере посетителя, а не в каталоге превью.

## Границы проверки

Проверки: `npm test` — 24, `npm run test:e2e` — 30 сценариев; сборка успешна.
Статический тестовый сервер перенаправляет `index.html`, как Tailscale;
офлайн-навигация использует каноническую страницу каталога в кеше.

Модульные проверки и Chromium на Linux покрывают запись через настоящий
MediaRecorder с тестовым микрофоном, обработку отказа доступа, отмену, сравнение
дублей, порядок записи/TTS, резервные копии и миграцию старой IndexedDB.
Это не проверка физического динамика или микрофона владельца и не приёмка Android/iPadOS.
