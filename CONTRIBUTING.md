# Вклады в PECSотеку

Публичное использование и форки регулируются [LICENSE](LICENSE). Для включения
чужих материалов в официальный репозиторий дополнительно нужно явное разрешение
ниже, чтобы GraphGiraffe мог в будущем предложить коммерческий выпуск.

Само открытие PR, обсуждение идеи или отметка автора коммита не заменяют согласия.
Перед слиянием каждый правообладатель включаемого вклада должен явно подтвердить
эту декларацию в PR со ссылкой на эту редакцию документа. Участник должен иметь
право давать разрешение, включая разрешение работодателя, если оно требуется.

нельзя считать охваченными декларацией без отдельного явного согласия.
