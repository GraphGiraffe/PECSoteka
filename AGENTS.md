# PECSотека

- Основное ТЗ: `docs/specification.md`. Планшет — целевое устройство, телефон и ПК поддерживаются. Визуальный ориентир — PlayRoom: светлый фон, спокойная палитра, мягкие звуки и анимации. Не переносить игровой движок, сетевые слои и операционные средства PlayRoom.
- Статическое HTML/PWA, ноль runtime-зависимостей. Источники в `public/`; `dist/` генерируется и не коммитится.
- Детский режим не меняет структуру альбома. Временная строка и буфер редактора отделены от сохранённых карточек. Смена вкладки не очищает строку. Незавершённый перенос не меняет IndexedDB.
- Любая постоянная правка проходит защищённый редактор и одну транзакцию `AlbumRepository.save` с проверкой revision. Фото — локальные Blob в IndexedDB, никогда не загружать их на сервер.
- Жесты: Pointer Events; отмена, второе касание, blur и resize не должны терять карточки. Учитывать настройку движения и системный reduced-motion.
- `main` — стабильная; `dev` — интеграция. Task → PR `dev` squash; выпуск → отдельный PR `dev` → `main` squash. Не force-push. Исключение первого коммита: пустой репозиторий инициализирован README.
- Проверки: `npm test`, `npm run build`, `npm run test:e2e`. Для E2E нужен Chrome/Chromium; `CHROME_BIN` задаёт путь. Браузерная проверка тестирует `dist/`, включая офлайн-кеш и изображения. После изменения исходников пересобрать затронутый артефакт и повторить соответствующие проверки.
- CI/Pages только вручную: `Publish Pages`, вход `ref` = точный SHA стабильного выпуска. Не добавлять автоматический прогон на каждый push без необходимости.
- Выпуск: ZIP содержимого `dist/` + `SHA256SUMS`, GitHub Release на проверенном main SHA, затем один Pages deploy и проверка опубликованных ресурсов. Не считать push подтверждением публикации.
